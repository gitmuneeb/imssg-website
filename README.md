# SMS Islamia Model Secondary School Website (IMS Garoora)

A modern, comprehensive, and responsive web portal for **S.M.S Islamia Model Secondary School**, Garoora, Bandipora, Jammu & Kashmir (UDISE: `01160100803`, Estd: 1982), modeled after premier institutional benchmarks like **SRM Welkin Sopore**.

---

## 🏫 Key Features Included & Fully Functional

1. **Top Institutional Utility Strip:**
   * Live UDISE badge (`01160100803`)
   * Campus Helpline & Office numbers
   * Direct links to official Instagram (`@imssgarooraofficial`) and Facebook pages
   * One-click **Student/Parent Portal** modal

2. **Hero & Live Marquee Section:**
   * High-impact multi-slide carousel featuring campus grounds, science laboratories, and board toppers
   * Real-time **flashing news ticker / notice marquee**
   * Key counters: 43+ Years of Legacy, 1,150+ Students, 100% Board Pass Rate, 48+ Faculty members

3. **Official Notice Board & Circulars Hub:**
   * Filterable categories: *All, Admissions, Examinations, Circulars, Events*
   * Instant search filter
   * **Full Official Letterhead Modal View** with downloadable text/slip and printable layout

4. **Academics & Wings (Four-Tier Educational Journey):**
   * Kindergarten & Pre-Primary Wing (Nursery, LKG, UKG)
   * Primary Wing (Classes 1st to 5th)
   * Middle School Wing (Classes 6th to 8th)
   * Secondary Wing (Classes 9th & 10th - JKBOSE Board)
   * Subject matrix, evaluation methodologies, and class timings

5. **Online Admissions Portal:**
   * Step-by-step admission roadmap
   * Age eligibility table (as per JKBOSE / SCERT guidelines)
   * Required documents checklist
   * **Fully working interactive online registration form** with validation
   * Generates a printable **Official Admission Acknowledgement Slip** with Application ID (e.g. `IMSS-2026-XXXX`) and timestamp

6. **Results & Merit Wall:**
   * JKBOSE Class 10th district toppers and distinction holders
   * **Interactive Marksheet Verification Simulator**: Enter any student Roll Number (or click sample roll numbers `26101`–`26105`) to instantly view and print an authentic **JKBOSE-formatted Marksheet & Evaluation Card**

7. **Interactive Fee Calculator (FFRC Compliant):**
   * Real-time calculation based on Class Wing, Bus Transport Route, and Concessions (Sibling 15% discount, Merit/Orphan 30% discount)
   * Transparent breakdown of monthly dues and annual charges
   * Print quote functionality

8. **Campus Facilities & Labs:**
   * Composite Science Laboratories (Physics, Chemistry, Biology)
   * ICT & Computer Education Lab (1:1 student-to-PC ratio)
   * Reference Library & Reading Room (4,500+ books)
   * Sports Grounds & Physical Fitness (Cricket, Volleyball, Athletics)
   * Islamic Studies & Moral Development (Seerat, Qirat, Adab)
   * Safe Bus Transport covering Bandipora-Srinagar highway routes
   * Health & Hygiene (RO drinking water, CCTV security, generator power backup)

9. **Photo & Video Gallery:**
   * Category filter (Campus, Academics, Sports, Cultural, Events)
   * Interactive full-screen **Lightbox Modal** with previous/next controls and captions

10. **Downloads & Mandatory Disclosures Center:**
    * Downloadable Admission forms, Syllabi, Uniform guidelines, Bus timetables
    * Statutory regulatory disclosures (UDISE, DSEK recognition, Building safety, Fire safety, FFRC compliance)

11. **Faculty Recruitment & Careers:**
    * Active teacher openings (TGT Science, TGT English, Computer Instructor, Kindergarten Teacher)
    * Working job application submission form

12. **Contact & Campus Location:**
    * Bandipora-Srinagar Highway, Garoora, Bandipora, J&K – 193502
    * Direct click-to-call, click-to-email, and click-to-WhatsApp
    * Embedded interactive Google Map

13. **Student / Parent Portal (Simulated Dashboard):**
    * Authentication with Admission No. & Mobile No.
    * Dashboard tracking student attendance (94.2%), homework diary, report cards, and fee receipts

14. **Floating Action Bar:**
    * Instant WhatsApp Inquiry button
    * Direct call shortcut
    * Smooth Back-to-Top scroll

## 🚀 Running the Project Locally

```bash
cd "C:\Users\user\.gemini\antigravity\scratch\imss-garoora-website"
npm install
npm run dev
```

Server runs at: `http://localhost:5173/`

## 📦 Production Build

```bash
npm run build
```
Build output is saved to the `dist/` directory, ready to deploy to Vercel, Netlify, Cloudflare Pages, or GitHub Pages.
